开着代理（魔法）出图很慢？

本站生成的图片是从各家图片服务器直接下载到你电脑上的。不开代理时一般很快；开着代理时，图片可能被绕到很远的节点，就会变慢。按下面任选一种方法设置即可。

方法一：生图时关掉代理（最简单）

推荐用本站生图时，先把代理软件关掉，或者切到「直连」模式。用完再打开。

方法二：切到「规则模式」

把代理软件从「全局模式」切到「规则模式」（Rule）。大多数情况下这样就够了；如果还是慢，再用方法三。

方法三：Clash Verge 加直连规则（开着代理也快）

  1. 打开 Clash Verge，点左侧「订阅」。
  2. 在你正在用的订阅上右键 →「编辑规则」，在「前置规则」里粘贴下面这几行，保存：
DOMAIN-SUFFIX,vinsen.top,DIRECT
DOMAIN-SUFFIX,ai-tudou.net,DIRECT
DOMAIN-SUFFIX,aitohumanize.com,DIRECT
DOMAIN-SUFFIX,getapib.org,DIRECT
DOMAIN-SUFFIX,myqcloud.com,DIRECT
  1. 再在同一个订阅上右键 →「编辑脚本」，把内容整个换成下面这段，保存（让这些域名用国内 DNS 解析，否则有些电脑直连时会连不上）：
function main(config) {
  const domains = ["vinsen.top", "ai-tudou.net", "getapib.org", "aitohumanize.com", "myqcloud.com"];
  config.dns = config.dns || {};
  const policy = config.dns["nameserver-policy"] || {};
  for (const d of domains) policy["+." + d] = ["223.5.5.5", "119.29.29.29"];
  config.dns["nameserver-policy"] = policy;
  return config;
}
  1. 回到「订阅」页，重新点一下当前订阅让设置生效，然后刷新本站页面。

如果你的脚本里原来已经有内容，请不要整个替换，把中间那几行加进原来的 main 函数里，或者找懂的朋友帮忙。

其他代理软件

ClashX、Clash Party、小火箭（Shadowrocket）、v2rayN 等，都可以在「规则」里把下面这些域名设成「直连（DIRECT）」： 
vinsen.top
ai-tudou.net
aitohumanize.com
getapib.org
myqcloud.com
